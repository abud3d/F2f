# F2F — واجهة المطعم

واجهة عملاء وإدارة مستقلة، تربط لاحقاً مع كاشير حسابي عبر عقد تكامل معتمد. لا تكرر المحاسبة أو إصدار الفواتير.

## المرحلة الأولى
تصميم HTML/CSS محلي متجاوب، صفحات القائمة والفروع والعروض والولاء، نموذج لوحة الإدارة، واختبارات قبول العميل والإدارة. لا مكتبات خارجية أو polling.

## حالة البيانات
الموقع المرجعي https://www.face2face.sa/؛ تعذر فتحه أثناء هذه المحاولة. بيانات النموذج تجريبية، ولا أسعار أو عروض معتمدة حتى التحقق. لا مدفوعات أو طلبات فعلية قبل اعتماد الربط.

## معاينة واجهة القائمة والفروع

شغّل خادم ملفات ثابتة من جذر المستودع، ثم افتح http://localhost:8000.

```sh
python3 -m http.server 8000
```

تعرض الواجهة مختارات عند فتحها. اختر أحد التصنيفات لعرض أصنافه، أو اكتب اسم صنف في البحث. يبحث خيار «مختارات» في كل التصنيفات عند كتابة كلمة. تحتوي بطاقات الفروع على روابط الخريطة والاتصال.

تُحدّث التصنيفات والأصناف والفروع من `data.js`. جُمعت البيانات الاسترشادية من المصادر أدناه بعد تعذّر فتح الموقع المرجعي، وتحتاج مطابقتها مع القائمة الرسمية ودليل الفروع قبل النشر. أحياء تغطية التوصيل لا تُعدّ عناوين فروع.

- القائمة: [الأصالة](https://hungerstation.com/sa-ar/restaurants/regions/ينبع/الأصالة/فيس-تو-فيس-57348)، [البحيرة](https://hungerstation.com/sa-ar/restaurants/regions/ينبع/البحيرة/فيس-2-فيس-198197)، [الصريف](https://hungerstation.com/sa-ar/restaurants/regions/ينبع/الصريف/face-2-face-100992)، [أمثلة الإفطار](https://www.snapchat.com/%40f2f_lounge/spotlight/W7_EDlXWTBiXAEEniNoMPwAAYeW1kaXBxYmt5AZsKzglqAZsKzehsAAAAAQ).
- الفروع: [البحيرة](https://restaurantguru.com/F2F-Yanbu)، [الصريف](https://maps.yango.com/en-sa/org/212225660473/)، [الجابرية](https://saudipeek.com/saudi-cafes/best-yanbu-cafes/).
- صورة الواجهة توضيحية من [Unsplash](https://unsplash.com/photos/poI7DelFiVA). صور الأصناف من قوائم التوصيل. تستخدم الواجهة خطًا بديلًا من النظام عند تعذّر تحميل الخط الخارجي.

تعمل الصفحة بملفات HTML وCSS وJavaScript ثابتة. لتجربة الواجهة، اختر كل قسم وتحقق من ظهور أصنافه، وابحث عن «بيتزا ترافل»، ثم امسح البحث وتحقق من عودة المختارات. جرّب روابط الخريطة والاتصال من بطاقات الفروع.
