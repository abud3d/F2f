# F2F v0.1.0 — وثيقة الويب

واجهة عربية وإنجليزية مستقلة. الموقع المرجعي تعذر فتحه، لذلك الهوية والتصنيفات مقترحة لا معتمدة. لا صور أو أسعار مؤكدة. HTML/CSS محلي دون JS أو مكتبات أو طلبات خلفية.

## الأرشفة
عناوين ووصف مستقلان، روابط داخلية وHTML دلالي. noindex للمعاينة حتى اعتماد المحتوى. قبل الإنتاج: canonical وhreflang على النطاق الرسمي، sitemap.xml، بيانات Restaurant/Menu المنظمة من حقائق معتمدة، جرد المسارات القديمة وتحويلات 301، إزالة noindex من صفحات الإنتاج العامة فقط.

## التكامل
كاشير حسابي مصدر الأسعار والضرائب والطلبات والفواتير. API موثق لاحقاً. PHP Native/PDO للإدارة وصلاحيات حسب الفرع وسجل تدقيق. توليد الصفحات عند التعديل المعتمد فقط. لا أسرار في مستودع عام.

## القبول
اختبار روابط الصفحات واللغات، الهاتف وإمكانية الوصول والأداء. الإدارة الحالية نموذج بصري، الحفظ والصلاحيات والربط تحتاج تنفيذ واختبار لاحقين. افتح index.html محلياً للمعاينة. لا طلبات أو دفع فعلي.
